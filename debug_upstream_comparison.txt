IMPORTANT CORRECTION
The broad backward-autocast scope is inherited from upstream, not introduced by the user.
Official train_ldm_only.py:318 enables autocast around backward at342 and optimizer.step at345.
User train_ldm_only.py:539 uses the same pattern, backward582, optimizer.step615.
Official train_repae.py:355 also has this broad scope, backward394/403/428.
The exact two-checkpoint reproduction still establishes this scope as the immediate failure
trigger in the adapted setup. It does not establish that the user invented the pattern, that
BF16 is generally broken, or that every upstream run fails.

PRESERVED BEHAVIOUR
- Timestep sinusoidal embedding and MLP are mathematically unchanged. Neither codebase
  multiplies t by1000. Official models/sit.py:53-77; user:51-65.
- adaLN scales/shifts/gates, residual equations, tanh GELU, LayerNorm eps1e-6 and 4x MLP
  are preserved. Official models/sit.py:118-142; user:75-91.
- Xavier initialization, timestep std.02, zero adaLN/output initialization are preserved.
  Official models/sit.py:224-260; user:185-214.
- Final LayerNorm is inherited. Official models/sit.py:151-163; user:100-109.
- AdamW beta1=.9, beta2=.999, epsilon1e-8, weight decay0, LR1e-4 and clip norm1
  come from upstream defaults. User adds2000-step warmup then constant LR.
- QK normalization off and fused attention on are upstream defaults.
- Fixed latent BN statistics during frozen-VAE LDM training are upstream behaviour.
- environment.yml is byte-identical in the source snapshots. User requirements pin the same
  torch2.3.1, accelerate1.1.1 and timm1.0.11 versions as the official environment.
Therefore zero weight decay, no QK norm, old torch version, unbounded gates or raw [0,1]
timestep encoding are not deviations that independently identify an implementation mistake.

MATERIAL DIFFERENCES
1. Conditioning: official full-width learned class embedding and learned CFG null token
   are replaced by attribute-specific MLPs, concatenation, L2 normalization, and zero-vector
   CFG dropout. Official models/sit.py:80-107/205/245; user models/embedder.py:26-70,
   models/sit.py:150-155/216-226. The normalized parent vector has fixed norm1 and RMS
   1/sqrt384=.0510 for SiT-S. Upstream has learnable magnitude. Importantly upstream starts
   at approximately .02 RMS, so the user's embedding is not smaller at initialization.
   Fixed magnitude versus learnable magnitude is the meaningful difference, not an arbitrary
   claim that normalized parents are inherently too small. Stability causality is untested.
2. Alignment objective: official advertised frozen-VAE recipe uses proj_coeff.5; user runs
   set it to0 and bypass encoders/projectors. The user is training a vanilla conditional SiT
   objective, not the advertised REPA-aligned objective. Frozen VAE itself matches the
   official LDM path; train_repae.py is the separate joint VAE/generator training method.
3. Recipe/task: published LDM example uses ImageNet, SiT-XL/1, E2E-VAVAE, batch256;
   user uses mammograms, SiT-S/2, standard SD-VAE f8d4, 256x192, batch8 (latest BF16
   failure) or batch64 (earlier failure). Cannot assume equivalent optimization dynamics.
4. Precision/compilation: official defaults fp16 and compile=True. Historical user failures
   were bf16 and compile=False. Current user launcher now uses mixed_precision="no"
   and experiment debug_3. The scope patch is validated in the historical eager BF16 setup;
   official mixed precision/compilation combinations have not been experimentally tested here.
5. Latents: official LDM script samples cached posterior moments; user encodes images online
   with frozen FP32 VAE and dataset-specific mean/std. Algebra is consistent, and inspected
   image scaling is consistent: dataset[0,1] -> *255 -> /127.5-1. No obvious double
   normalization or image-range mistake was found in the active image-mode path.
6. User adds finite-value checks, failure snapshots, validation, and learning-rate warmup.
   These are intentional diagnostics/training changes, not evidence of a new instability bug.

APPROPRIATE USER FIXES
- Rectangular positional grids/unpatchification are required for256x192.
- Explicit SiT-S decoder_hidden_size384 matches its hidden size. Upstream SiT-S helpers
  inherit decoder_hidden_size768; the user avoids that width mismatch.
- Disabling REPA cleanly when proj_coeff0 avoids upstream model assumptions that zs exists.

DIAGNOSIS IMPLICATION
The immediate backward-autocast trigger has experimental proof from the prior diagnosis.
The strongest model-specific differences to ablate for hidden activation growth are conditioning
normalization/null-token design and the absence of alignment, holding all other settings fixed.
This comparison alone does not show either caused the growth. No training source was edited
and no new training job was submitted for this comparison.
